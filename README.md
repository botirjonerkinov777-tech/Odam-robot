# SO'Z USTASI — Topqir so'zlar o'yini

**So'z Ustasi** — maktab o'quvchilari uchun yaratilgan interaktiv so'z topish o'yini. O'yinchi yashirin so'zni cheklangan urinishlarda topishga harakat qiladi, shu orqali lug'at boyligini oshiradi va imlo qoidalarini mustahkamlaydi.

## 🚀 Loyihaning asosiy imkoniyatlari

- **Bir nechta til:** o'zbek va ingliz tilidagi so'zlar.
- **Darajalar:** boshlang'ich (4 harfli), o'rta (5 harfli) va yuqori (6 harfli) so'zlar.
- **Mavzular bo'yicha so'zlar:** hayvonlar, o'simliklar, maktab, kasblar va mamlakatlar.
- **Yakka tartibdagi o'yin:** o'quvchi so'zni mustaqil topadi.
- **Jamoaviy o'yin:** ikki jamoa navbatma-navbat so'z topib, ball to'playdi.
- **Maslahat tizimi:** qiyin paytda bitta harfni ochib beruvchi maslahat tugmasi.
- **Vaqt rejimi:** vaqt bilan yoki urinishlar soni asosida o'ynash.
- **Musiqa tanlash:** mavjud musiqalardan birini tanlash yoki ovozni o'chirish.
- **Natijalar:** yakunda to'plangan ball va topilgan so'zlar ro'yxatini ko'rish.
- **Interaktiv effektlar:** harflar rangi o'zgarishi (yashil — to'g'ri joyda, sariq — so'zda bor, kulrang — yo'q) va g'alaba konfetti animatsiyasi.

## 🛠️ Ishlatilgan texnologiyalar

- **HTML5** — sahifa tuzilishi.
- **CSS3** — dizayn va animatsiyalar.
- **JavaScript** — o'yin mantiqi va interaktiv funksiyalar.
- **Google Fonts (Poppins)** — shrift.

Loyiha hozircha frontend asosida ishlaydi. Server yoki ma'lumotlar bazasini ishga tushirish talab qilinmaydi.

## 📁 Loyiha tuzilishi

```
SozUstasi/
├── index.html       # Asosiy sahifa va interfeys
├── style.css        # Dizayn va stillar
├── script.js        # O'yin logikasi
├── words.js         # Mavzular va darajalar bo'yicha so'zlar bazasi
├── sounds/          # Musiqa va ovoz fayllari
└── README.md        # Loyiha haqida ma'lumot
```

## ▶️ Loyihani ishga tushirish

1. Loyihani ZIP shaklida yuklab oling va arxivdan chiqaring.
2. `SozUstasi/` papkasini oching.
3. `index.html` faylini Google Chrome, Microsoft Edge yoki boshqa zamonaviy brauzerda oching.
4. **Boshlash** tugmasini bosing va til, daraja hamda o'yin rejimini tanlang.

> Eslatma: audio fayllar to'g'ri ishlashi uchun ularni `sounds/` papkasida saqlang. Internet aloqasi Google Fonts shriftini yuklash uchun kerak bo'lishi mumkin.

## 🎮 Qanday o'ynaladi?

1. Bosh sahifada **Boshlash** tugmasini bosing.
2. Tilni va mavzuni tanlang.
3. Daraja (so'z uzunligi) va o'yin rejimini (yakka yoki jamoaviy) belgilang.
4. Urinishlar soni va vaqt sozlamalarini tanlang.
5. So'zni kiriting — har bir harf rangi to'g'ri javobga yaqinligingizni ko'rsatadi.
6. So'zni toping va yakuniy natijangizni ko'ring.

## 🧩 So'zlar bazasi

So'zlar `words.js` faylida saqlanadi. Yangi so'z qo'shish yoki mavjudini tahrirlash uchun shu fayldagi tegishli til, mavzu va daraja bo'limini o'zgartirish mumkin.

So'z qo'shayotganda uning uzunligi tanlangan darajaga mos ekanini va imlosi to'g'riligini tekshiring.
